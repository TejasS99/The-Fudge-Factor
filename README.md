# The Fudge Factor

Welcome to The Fudge Factor, your ultimate destination for rich, fudgy, and delicious homemade brownies in Solapur!

## About This Project
This is the front-end website for a local homemade brownie business. It is designed to showcase our irresistible, freshly baked brownies and make it easy for customers to place orders. 

## Features
* **Quick Ordering:** Order directly via WhatsApp.
* **Fast Service:** Convenient pickup or delivery available within 2 hours of ordering.
* **Local Focus:** Proudly serving the Solapur community.
